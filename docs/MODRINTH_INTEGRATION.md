# Modrinth integration

The launcher uses the documented Modrinth v2 read endpoints for third-party discovery. Averion Client declares runtime constraints via Fabric metadata and the versioned distribution manifest, and consults Fabric Loader when it needs to detect an installed integration. It makes no Modrinth API requests.

- Discover with search or project IDs. Query `GET /v2/project/{id|slug}/version` with JSON-array query filters `loaders=["fabric"]` and `game_versions=["<exact game id>"]`. Recheck response filtering, release policy, Java, side metadata and jar constraints before installation. Persist immutable project and version IDs. Select an explicit file based on primary status and compatibility or a pinned file identity. [Search](https://docs.modrinth.com/api/operations/searchprojects/), [List versions](https://docs.modrinth.com/api/operations/getprojectversions/).
- Build a dependency graph from each chosen version's dependency list. Follow exact required version IDs, or select a compatible release for project-only edges. Reconcile multiple constraints, detect cycles and reject unresolved or incompatible dependencies. Optional dependencies need explicit profile policy. Respect incompatible edges and Fabric `breaks`. Embedded libraries are part of their parent jar. Inspect Fabric metadata too because provider dependency lists can omit declared runtime requirements. [Version dependency fields](https://docs.modrinth.com/api/operations/getversion/), [Fabric metadata](https://docs.fabricmc.net/develop/loader/fabric-mod-json).
- Use an identifying User-Agent, cache results, observe rate headers, and back off on 429 and transient failures. Download from the upstream file URL over HTTPS and verify byte count and SHA-512. When selecting an Averion-required dependency, also match the signed manifest pin before installation. [API usage and file identifiers](https://docs.modrinth.com/api/), [Find version by file hash](https://docs.modrinth.com/api/operations/versionfromhash/).

Keep distinct ownership records for Averion-required files, launcher-managed optional mods and user-managed files. Stage and validate changes as a single profile transaction. A resolver may report and explain conflicting mods, including duplicate Fabric IDs, but cannot silently remove a user file. Third-party downloads remain upstream even when they are recommended. Review licenses, upstream distribution terms and exact file metadata before permitting any mirror or preset.
