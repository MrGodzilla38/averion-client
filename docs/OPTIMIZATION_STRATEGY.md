# Optimization strategy

Averion-owned optimizations target measured costs in features Averion controls. Keep hot callbacks allocation-light, defer disk and network work off the game thread, and invalidate caches explicitly. Benchmark a fixed world, route, settings, hardware and JVM against vanilla Fabric plus Averion. Compare frame-time percentiles, tick cost and memory after a warm-up. Recheck visual correctness as well as throughput.

An optional upstream integration is an exact tested combination in a launcher profile with client-side capability detection when Averion needs it. User-installed mods remain user-owned. Required dependencies are exact build requirements listed in the jar and release manifest. Phase 00 has no optimizer dependency or curated preset.
